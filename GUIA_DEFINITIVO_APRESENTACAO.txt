============================================================
GUIA DEFINITIVO DE INSTALAÇÃO E APRESENTAÇÃO - LEARNHUB
Expo SDK 57 + API e MySQL hospedados
============================================================

Este guia descreve a configuração atual do projeto. A API e o banco
de dados ficam hospedados; o computador da escola executa somente o
Expo/Metro. Não é necessário instalar MySQL, configurar backend/.env
ou abrir um túnel manual para a API.


============================================================
1. PROGRAMAS NECESSÁRIOS
============================================================

- Node.js 22.13 ou superior;
- npm (instalado junto com o Node.js);
- Expo Go compatível com o Expo SDK 57;
- acesso à internet no computador e no celular.

Confirme as versões no CMD:

node --version
npm --version

Se o Node.js for mais antigo que 22.13, atualize-o antes de continuar.


============================================================
2. PREPARAR EM UM COMPUTADOR NOVO
============================================================

Copie ou clone a pasta completa do projeto. Depois, abra o CMD:

cd /d C:\CAMINHO\PARA\LearnHub
npm install

O projeto utiliza npm workspaces. Um único npm install prepara o app
e também as dependências do backend usadas em desenvolvimento local.


============================================================
3. INICIAR PELO CMD
============================================================

Na pasta do projeto, execute:

npm start

Esse é o comando oficial. Ele faz automaticamente:

1. valida a versão do Node.js;
2. testa a API hospedada e a conexão com o banco;
3. prepara o Cloudflare Tunnel do Expo;
4. inicia o Metro;
5. valida o manifesto que será aberto pelo Expo Go.

Quando estiver pronto, o terminal mostrará:

====================================
LEARNHUB PRONTO
Expo SDK: exposdk:57.0.0
Conexão: túnel público
====================================

Abra o Expo Go e leia o QR Code. Para encerrar, pressione Ctrl+C uma
vez. Encerrar normalmente não é tratado como falha.

O comando antigo continua funcionando como alias:

npm run escola


============================================================
4. INICIAR COM DOIS CLIQUES
============================================================

Também é possível dar dois cliques em:

INICIAR_LEARNHUB.cmd

O arquivo instala dependências quando necessário e chama npm start.
Se houver um erro real, a janela permanece aberta para mostrar a
mensagem de diagnóstico.


============================================================
5. QUANDO A REDE BLOQUEAR O TÚNEL
============================================================

O iniciador tenta usar o túnel público porque redes escolares costumam
isolar dispositivos. Se a rede bloquear o Cloudflare, ele muda para
LAN automaticamente.

Para iniciar diretamente em LAN:

npm run dev

Nesse modo, computador e celular devem estar no mesmo Wi-Fi ou hotspot.
Permita Node.js em redes privadas quando o Firewall do Windows pedir.


============================================================
6. DIAGNÓSTICO
============================================================

Para testar a configuração sem abrir o aplicativo:

npm run diagnose

O estado correto da API hospedada é semelhante a:

API: online
Banco de dados: connected

Se aparecer que a API ou o banco estão indisponíveis, confirme a
internet e tente novamente. O npm start interrompe antes do Expo se o
serviço hospedado estiver realmente indisponível.


============================================================
7. DESENVOLVIMENTO LOCAL OPCIONAL
============================================================

Somente quem quiser desenvolver com API e MySQL locais precisa copiar
backend/.env.example para backend/.env e configurar o banco. Depois:

npm run dev:local

Essa opção não é necessária para apresentar ou usar o sistema normal.
Nunca publique a porta 3306 do MySQL diretamente na internet.


============================================================
8. TESTAR O CRUD
============================================================

No Expo Go, confirme:

1. cadastro de um novo usuário;
2. login com o usuário criado;
3. consulta/listagem dos registros;
4. edição de um registro;
5. exclusão de um registro;
6. logout e novo login.

As operações passam pelo aplicativo, pela API HTTPS hospedada e pelo
MySQL hospedado. A senha deve permanecer armazenada somente como hash.


============================================================
9. SOLUÇÕES RÁPIDAS
============================================================

"node" ou "npm" não é reconhecido
  Instale o Node.js 22.13 ou superior e reabra o CMD.

Dependências ausentes
  Execute npm install na raiz do projeto.

Túnel bloqueado
  Use npm run dev e conecte celular e computador ao mesmo hotspot.

QR Code abre, mas o app não carrega
  Aguarde a mensagem LEARNHUB PRONTO. Se necessário, encerre com
  Ctrl+C, execute npm start novamente e leia o novo QR Code.

API ou banco indisponível
  Execute npm run diagnose. Não é necessário instalar MySQL na máquina
  escolar, pois o serviço normal usa a infraestrutura hospedada.
